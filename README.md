# Sprint Challenge: Low-Level Logic & Data Structures

A deep dive into building fundamental computing operations completely from scratch. This challenge enforces strict constraints to eliminate high-level abstractions, reinforcing the core mechanics of memory allocation, array manipulation, and stack frame execution.

## ❌ Constraints Applied
* No built-in helper functions (`sort()`, `sum()`, `max()`, `min()`, `append()`, `pop()`)
* No external libraries
* Pure algorithmic logic

## 💻 Solutions Included

### 1. Pure Recursion (Power Calculation)
Calculates \(x^y\) natively using continuous stack frame operations without standard mathematical shorthand or built-in exponents, handling both positive and negative integer components.

### 2. Manual Stack Implementation (String Reversal)
A custom stack object structure engineered around sequential array indexing and strict pointer tracking to reverse character strings manually.

## 📝 Challenge Reflection
Stripping away high-level syntactic sugar fundamentally modifies your developer perspective. Forcing logic into manual pointer tracking and explicit index mapping exposes the underlying time and space complexity hidden behind everyday shorthand. True engineering excellence stems from fully mastering what happens underneath the abstract API layer.
